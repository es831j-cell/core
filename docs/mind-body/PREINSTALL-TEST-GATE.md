# Code388+ pre-install gate

1. Current Lumi canonical source is healthy and matches the installed base version.
2. Compile the complete target Android release with the preserved Lumi signing identity.
3. Validate the update manifest, every SHA-256 entry, sourceRecord base hash, target canonical archive and signing certificate.
4. Static/pure-Java intelligence foundation tests pass where runnable in the build environment.
5. Device visual regression: Home workstation, approved layered pyramid geometry, state colors/transitions, and required direct Home actions.
6. Network smoke tests record fresh-data success/failure without invented results.
7. Black Box records effectiveness/latency/speech/update deltas without hidden chain-of-thought.
8. Lumi creates a protected local checkpoint, Android presents its normal installer approval, and Lumi native post-install validation passes after replacement.
9. Export a fresh Black Box and complete outstanding behavioral acceptance on the actual device.

Guardian is retired and is not part of the Code388+ install or certification path.
